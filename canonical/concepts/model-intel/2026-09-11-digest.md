### 🆕 DeepSeek V4.1 Flash SHIPPED — 10 September, MIT open weights, and it claims the open-weight crown

Yesterday's run said, in terms: *"no technical report, no official benchmark suite, no model card, and no permanent API id... a cheaper-and-better claim with no published numbers is a marketing sentence."* **All four gaps closed within 24 hours.** That reversal is the single most consequential thing on this page, so it gets the detail.

- **Released 10 September 2026.** **The canonical API id is now plain `deepseek-flash`.** First-party changelog, verbatim: *"Change the model name to `deepseek-flash` to call the latest V4.1 Flash model"*, and *"The previous-generation models V4 Flash and V4 Flash Vision Exp have been retired; for compatibility, the model names `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are temporarily routed to V4.1 Flash."* [CONFIRMED first-party — [DeepSeek API changelog](https://api-docs.deepseek.com/updates/)]
- 🔴 **A dated price event three days out, and it is a cut, not a rise.** First-party, verbatim: *"After 12:00 Beijing Time on September 14, 2026, and until the future release of V4.1 Pro, all requests to `deepseek-v4-pro` will be routed to V4.1 Flash and billed at the V4.1 Flash price."* **Anything pinned to `deepseek-v4-pro` gets ~4.4× cheaper on input and ~3.3× cheaper on output without changing a line of code** — and simultaneously stops being the model it asked for. [CONFIRMED first-party — [changelog](https://api-docs.deepseek.com/updates/); the ratios are my arithmetic on the published table below]
- **Pricing, first-party, per 1M tokens.** Off-peak: **$0.003 cache-hit input · $0.15 cache-miss input · $0.60 output.** Peak is exactly double: **$0.006 / $0.30 / $1.20**. Off-peak is **01:00–04:00 and 06:00–10:00 UTC, Monday to Friday**. For comparison on the same page, `deepseek-v4-pro` off-peak is **$0.66 input / $1.98 output**. **Context 1M, max output 384K.** [CONFIRMED first-party — [DeepSeek pricing](https://api-docs.deepseek.com/quick_start/pricing/)]
- **Architecture, and it is a new family rather than a version bump.** **552B backbone plus 196B "Engram" conditional-memory parameters**, activating **8B per token during prefill and 16B during decode**; a **40-layer backbone split into a 20-layer causal encoder and a 20-layer decoder**; **CSA2** cross-layer attention reuse (each attention layer assigned Full, Reindex or Reuse); **FP4 main KV cache** (E2M1 with one E4M3 scale per 16 channels); **DSpark speculative decoding**. Result claimed: **global KV cache footprint of 890 bytes per token, about 1/4 of V4-Flash**, and persistent cache about 1/8. **Trained from scratch on 45T tokens of mixed text and images** — multimodal is native, not bolted on. [CONFIRMED as published — [MarkTechPost technical write-up](https://www.marktechpost.com/2026/09/10/deepseek-ai-released-deepseek-v4-1-flash-with-1m-context-fp4-kv-cache-and-cross-layer-attention-reuse/), [datanorth](https://datanorth.ai/news/deepseek-releases-deepseek-v4-1-flash), [cryptobriefing](https://cryptobriefing.com/deepseek-v4-1-flash-model-launch/)]
- **The benchmark table, which is the part that touches routing.** Published figures: **Terminal-Bench 2.1 — V4.1 Flash 90.6 vs Opus 5 89.1 vs GPT-5.6 Sol 88.8 vs V4-Flash 82.7.** **DeepSWE v1.1 — 74.2 vs Opus 5's 74.0 and Sol's 73.0.** **Automation-Bench — 54.8 vs 50.3 and 45.8.** **Codeforces rating 3471.** **And the honest counter-example, which is in the same table: GPQA Diamond 90.9 vs Opus 5's 93.4.** [CONFIRMED as published by the vendor and reproduced by a technical outlet — [MarkTechPost](https://www.marktechpost.com/2026/09/10/deepseek-ai-released-deepseek-v4-1-flash-with-1m-context-fp4-kv-cache-and-cross-layer-attention-reuse/)] ⚠️ **These are vendor-run numbers on a launch day. [CONFIRMED — [deepseek-ai/DeepSeek-V4.1-Flash on Hugging Face](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash), [MarkTechPost](https://www.marktechpost.com/2026/09/10/deepseek-ai-released-deepseek-v4-1-flash-with-1m-context-fp4-kv-cache-and-cross-layer-attention-reuse/)] **Yesterday's digest said "do not assume the local lane inherits this." **2. 🆕 A dated, first-party price event on Friday that silently changes what a pinned model returns — and it cuts both ways.**
**From 12:00 Beijing time on 14 September, `deepseek-v4-pro` requests are routed to V4.1 Flash and billed at Flash prices.** The billing half is a straight ~4× saving. **The behavioural half is the risk: any code, config or eval that names `deepseek-v4-pro` will keep working, keep returning results, and quietly be talking to a different model.** The same applies to `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp`, both retired and temporarily aliased.
**I ran that grep rather than leaving it as a to-do, and it found exactly two sites — one live, one documentation:**
- 🔴 **`tools/ask-trial.py` line 44 pins `"model": "deepseek-v4-flash"` — a RETIRED id, currently alive only because DeepSeek is "temporarily" aliasing it.** It works today. It works Friday. It stops working, or silently changes behaviour, whenever DeepSeek ends the alias, and nothing in our tree would report that.
- 🔴 **`tools/lanes.py` line 45 documents the deepseek lane as `DeepSeek-V4-Flash-0731, $0.14/M in, $0.28/M out`.** Against first-party pricing that is **wrong in the direction that matters: real output is $0.60/M off-peak and $1.20/M peak, so the registry understates output cost by 2.1× to 4.3×.** An agent budgeting a trial call from `lanes.py` under-estimates it by that factor, and `lanes.py` is the machine-readable registry §7.2 names.
- `canonical/concepts/verified-model-map-2026-08-28.md` carries the same stale id and price in prose. **No other file in the tree references any of the three ids.**
**Neither is fixed here, and the reason is a named gate, not reluctance:** both files sit on the **metered spend path** that AGENTS.md §7.2/§7.2.a governs, and §14.4(a) lists *"an existing safety gate you must not route around"* as a legitimate park. **Repinning a metered lane's model id and rewriting the spend registry's own cost figures are edits to that gate, not to a doc.** **Owner: a session that owns `tools/ask-trial.py` and `tools/lanes.py`, or Adrian.
