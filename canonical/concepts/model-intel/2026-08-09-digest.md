## B. INNOVATIVE USES — what people are actually doing

**This week's theme is unusually coherent, and it is not a model: it is context.** Independent HN signal, the research literature, and the Claude Code community all converged on the same problem in the same window.

- **"Context rot" now has measurements behind it.** Chroma's study found **all 18 frontier models tested degrade measurably as input length grows** — via lost-in-the-middle, attention dilution, and distractor interference. The framing that follows: *most agent failures are not model failures, they are context failures.* [CONFIRMED as a study finding — [Sourcegraph](https://sourcegraph.com/blog/context-engineering), [Digital Applied](https://www.digitalapplied.com/blog/context-engineering-agent-reliability-playbook-2026); the 18-model figure is secondary-reported, not read first-party]
- **The ACE paper (Agentic Context Engineering, ICLR 2026) proposes a concrete fix worth understanding:** represent context as a collection of **structured, itemised bullets**, and **update it incrementally rather than rewriting the whole block**, using a Generator / Reflector / Curator loop that refines an evolving playbook. [CONFIRMED as published — [Sourcegraph](https://sourcegraph.com/blog/context-engineering); see also [arXiv on context rot in long-horizon search](https://arxiv.org/pdf/2606.29718)]
- **The Karpathy "LLM Wiki" pattern went viral in April 2026 and is now a named agent-design pattern:** the agent maintains an interlinked markdown wiki of what it has learned, **queries it before searching, and updates it after**. [CONFIRMED as a pattern in circulation — [HackerNoon](https://hackernoon.com/your-ai-agent-doesnt-have-a-search-problem-it-has-a-context-problem)] **⚠️ Note for us: this is not new information to the vault — there is already an `llm-wiki-setup` skill installed, and the vault IS an instance of this pattern.** The finding is not "adopt this"; it is that the wider field has converged on the architecture we already run.
- **Claude Code skill-authoring guidance has hardened into specifics worth applying:** install **fewer, better-scoped** skills; keep **skill bodies under ~500 tokens and link to longer reference files read on demand**; put global rules in `CLAUDE.md` and domain-specific workflows in skills. **Agent Skills is now an open cross-IDE standard** (Claude Code, Cursor, Gemini CLI) rather than an IDE-locked plugin format. [CONFIRMED directionally across [Firecrawl](https://www.firecrawl.dev/blog/best-claude-code-skills), [Developers Digest](https://www.developersdigest.tech/blog/best-claude-code-skills-2026), [Shareuhack](https://www.shareuhack.com/en/posts/claude-code-community-skills-agent-fleet-guide-2026); all vendor/community sources — INFERRED as best practice, not vendor-measured]
- **HN signal this week reinforces the same theme.** The top AI-model item was **"Git for LLMs — a context management interface"** (106 pts, twigg.ai). Also surfacing: **an MCP server packaged inside Chromium** (BrowserOS, 46 pts), **Dexto** for connecting agents to real-world tools, **figma-use** (CLI to drive Figma for agents, 115 pts), and **Lume 0.2** for unattended macOS VMs (154 pts). [Per [2026-08-09-raw-signal.md](2026-08-09-raw-signal.md), free HN API]
- **The HN consensus has shifted from capability to workflow fit** — whether tools preserve context over long sessions, inspect codebases without re-discovering structure every session, and compose with external systems. [INFERRED synthesis — [Developers Digest](https://www.developersdigest.tech/blog/what-hacker-news-gets-right-about-ai-coding-agents-2026)]
